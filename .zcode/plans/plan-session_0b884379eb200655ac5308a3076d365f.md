支持 @K 对象级作用域与自定义 key/prefix 写法：

```kotlin
// 对象带 k：自定义前缀
@K(k = "demo")
object DemoState {
    @K(k = "xyz1") var xyz by persisted(1)   // key = "demo-xyz1"（属性 k 覆盖后缀）
    var abc = 100                            // key = "demo-abc"
}

// 对象不带 k：前缀 = 对象简单名
@K
object OtherState {
    var n = 0                                 // key = "OtherState-n"
}
```

## 语义规则
- **`@K object`（不带 k）**：其内所有 var 属性自动持久化，key 前缀 = 对象简单名
- **`@K(k = "demo") object`（带 k）**：前缀改用自定义值 `demo`（即"对象可自定义前缀"）
- **属性 `@K(k = "x")`**：key 后缀覆盖为 `x`
- 最终 key = `[前缀-]后缀`，分隔符固定 `-`；`@K object` 内**所有** var 自动持久化（无需逐个标注）
- 顶层 `@K` 属性行为不变（裸属性名，向后兼容；带 k 则用 k）
- 普通对象内仍只处理带 `@K` 的成员属性；嵌套对象不递归（与现状一致）

## 改动

### 1. datastore-extensions/Persisted.kt
`K` 注解增加 `val k: String = ""` 参数，`@Target` 增加 `AnnotationTarget.CLASS`（可标注对象）。

### 2. persist-plugin/PersistPlugin.kt（核心）
- 文件级类处理时读取对象上的 `@K`（含 `k` 参数）→ 计算前缀（有 `k` 用 `k`，否则用对象简单名）；`@K object` 内全部成员属性参与重写
- key 计算改为 `[前缀-]后缀`；注解 `k` 通过 `getValueArgument(0)` 读取 IrConst 字符串
- 新增委托属性重写：委托初始化为 `persisted(<字面量>)` 调用时，提取字面量默认值，访问器重写为 `persistedGet<T>(key, 字面量)` / `persistedSet<T>(key, value)`；非字面量默认值报编译错误；自定义（非 persisted）委托保持原样
- 顶层委托属性也统一重写（key/默认值与现状一致，行为不变，模型统一为"by persisted(默认值) 只是指定默认值的语法糖"）

### 3. app 模块（demo）
- DemoState.kt 改为对象写法并演示自定义前缀/后缀；AppUi.kt 改用 `DemoState.xyz` / `DemoState.abc`

### 4. README
补充对象作用域语法、自定义前缀/后缀与 key 规则说明。
